## 海报工坊微信小程序（首版）

在小程序云原生（微信原生 WXML/WXSS/JS + WorkBuddy Cloud）下从零搭建海报生成小程序，
应用 ID `wbapp_RKMsdv785EYm9zo0aM2r0m`，工程根目录即会话工作区根。

### 功能范围
- **素材库**：内置 8 张国风素材（风景/山水/建筑/人文各 2 张，AI 生成的压缩 jpg，
  位于 `assets/materials/`），云端素材入库（AI 生成 / 相册上传）。
- **模板库**：3 套内置多图层模板（国风传统文化 / 水墨山野 / 东方建筑），
  每层带 `slot` 标识；打开模板只需改文字位与贴图位。任意海报可「存为模板」复用。
- **历史记录**：`poster_records` 按 `owner_id` 私有，缩略图走签名 URL + `wx.downloadFile`；
  分享走 `open-type="share"` 按钮 + `onShareTimeline`，以导出图作为分享图。
- **AI**：文生图 / 图生图（`wx.chooseMedia` 上传参考图）+ 主题文案生成。
  图像模型 `hunyuan-image-alpha` 与文本模型都走 `cloud.llm.chat.completions`（流式），
  SDK 无独立图像端点。

### 关键技术决策
- **设计坐标系**：模板一律 750×1200 逻辑坐标，Canvas 导出 ×2 = 1500×2400，
  解决不同机型舞台尺寸不一致的问题（`utils/poster.js`）。
- **图层匹配严格按 slot**：`applyTextEdits` / `applyImageReplacements` 一律用
  `layer.slot || layer.id` 匹配。曾用「按数组下标回退」导致换图时贴到错误图层，已修复并加回归用例。
- **图层的远端素材**：云端素材在图层上存 `storagePath`（对象路径）而非签名 URL，
  渲染时再 `createSignedUrl` → `wx.downloadFile` 落地成本地临时文件画进 Canvas。
- **登录**：`wx.login` → `cloud.auth.signInWithWechat`，`app.requireSignIn()` 静默兜底。
- **数据库 RLS**：`poster_materials` / `poster_templates` 公开读（内置资源对所有人生效），
  写入仅限本人；`poster_records` 读写删全部仅限本人。12 条策略，两道门（GRANT + POLICY）都做了。

### 调整：上传图片自动压缩到 1MB 以下
新增 `utils/image.js`，素材页与选图页共用。

**为什么不能靠 `sizeType:'compressed'`**：那只是系统级粗压，不保证落在阈值内
（现代手机照片动辄 3-5MB）。所以 `chooseMedia` 改回 `sizeType:['original']`，
压缩逻辑自己控制。

**阶梯策略**（每步都用 `fs.stat` 量真实字节，以实际结果决定是否收手）：
1. 原图已≤1MB → 直接放行，不做无谓的二次压缩
2. 逐级降质量 80 → 68 → 56 → 44，达标即停
3. 质量到底仍超标 → 降分辨率，长边收到 1600 / 1280 / 1024
4. 分辨率本来就够小 → 不做无意义的缩放
5. 全压完仍超标 → 返回 `stillOversize: true`，调用方**必须显式报错**，
   不静默上传一张巨图（素材页与选图页都已接上这个分支）

**踩坑（重要）**：降质量阶梯最初写成「压上一档的产物」，
即 `compressOnce(current, q)`。这样 4 档下来画质会**累积劣化**，
比一次压到位更糟。已改为每档都 `compressOnce(filePath, q)` 从原图重压，
降分辨率分支的 canvas 输入同样是原图。已加两条回归用例锁住。

canvas 兜底缩放需要在页面里有画布节点，picker 页已加隐藏
`<canvas id="compress-canvas">`（用 fixed 移到视口外而非 display:none，
后者在部分基础库上会导致画布不渲染）。

新增 `tests/image-compress.test.js` 11 项用例。当前测试总计 **54 项**（25+9+9+11），全绿。

### 模板页改为真实 canvas 画板缩略图
原先缩略图是 CSS 渐变 + 标题文字的占位，与实际版式差距很大，

另有 `describeLayers` / `layerSummary` 统计图层构成。

**列表展示**（新增 `utils/thumbnail.js` + 模板页 WXML/WXSS 重写）：
- 真实 canvas 缩略图（`selectAll('.tpl-canvas')` 批量取节点，下标与 `wx:for` 一一对应）
- 右上角层数徽标 + 按类型分色标签：文字 N /贴图 N / 贴纸 N / 印章 N

**踩坑**：canvas 节点可能比数据晚挂载首帧，`selectAll` 会返回空数组。
