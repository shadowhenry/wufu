## 需求变动：去掉 canvas 编辑器，全部改成 AI 图生图

Henry 定下的新逻辑（五条）：
1. 只开放海报一类物料，其余（明信片/名片/易拉宝/请柬）隐藏，之后再开
2. 素材 = 图生图：素材图作底图，用户可加贴图与文字，也支持提示词
3. 模板 = 图生图：模板自带底图作参考图，用户可换图换字，替换模板里的文字与贴图
4. 拼贴 = 图生图：提示词 + 用户上传的图
5. AI 创作 = 纯文生图

架构选择（AskUserQuestion 确认）：
- 底图作**参考图**，文字与贴图说明**拼进提示词**（模型只收文本，图像模型走
  `cloud.llm.chat.completions` 的 `hunyuan-image-alpha`，没有真正的 image input）
- 模板直接用自带底图当参考图
- 删除编辑器，入口全部改到新创作页

## 进来就弹底部登录框（Henry：「都要用 AI 生图，那就必须都登录」）
首页未登录时 `showLoginGate` → 底部弹层（`login-mask`/`login-sheet`，从下滑入），
主按钮 `signInFromGate` → `app.doSignIn()`（弹层本身已是明确授权动作，
**不再叠 requireSignIn 的确认弹窗**），另有「稍后再说」→ `closeLoginGate`。

⚠️ **冷启动时序坑**：`app.onLaunch` 的 `restoreSession()` 是异步的，
首页 `onLoad/onShow` 常常先跑完，已登录用户会被误判成游客而弹框。
修法：`app.js` 把 Promise 存进 `globalData.sessionReady`，新增
`whenSessionReady()`；首页 `syncIdentity()` 必须 await 它再 setData，
并且**登录态由 false 变 true 时补拉一次** loadRecent/loadUsedTemplates。

- 弹过一次后用户点「稍后」→ `gateDismissed = true`，本次进首页不再自动弹；
  真要用功能时创作页 `ensureWritable('使用 AI 生成')` 还会再拦一次。
- 登录失败保持弹层、恢复按钮可点（报错由 `doSignIn` 内 `reportError` 统一出）。
- 测试替身（3 个文件的 `global.getApp`）都要补 `whenSessionReady` / `doSignIn`，
  否则首页一跑就 TypeError。

## 创作区固定 + 图片自适应 + 可拖动看全（Henry，取代上一条比例框方案）
上一轮做的「底图预览框跟随出图尺寸锁比例」被否：**创作区大小必须固定不变**。
- 结构改为 `.ref-stage`（固定 640rpx，圆角/overflow hidden）
  → `scroll-view.scroll-x/y`（图片比区域大时上下左右拖）
  → `.ref-canvas`（inline-block，尺寸由 JS 下发）→ `image mode="aspectFit"`。
- `create.js`：`STAGE_WIDTH = 694`（750 - 左右 28 内边距）、`STAGE_HEIGHT = 640`；
  `syncRefSize()` 按「**至少铺满一条边**」算显示尺寸：
  `width = max(STAGE_WIDTH, STAGE_HEIGHT * ratio)`、`height = width / ratio`。
  竖图贴宽高度溢出（可上下拖），横图贴高宽度溢出（可左右拖），正方形贴宽。
- 出图尺寸**只交给模型**，不再影响预览区；`chooseSize` 不再调 sync 方法。
- 空状态 `ref-picker` 也固定 640rpx，选图前后区域不跳。

⚠️ 踩坑备忘：
- `scroll-view` 双向滚动 → 子元素必须 `display:inline-block` + 父 `white-space:nowrap`，
  否则横向滚不动；且 scroll-view 自身要有确定高度（这里 100% 继承 640rpx 的 stage）。
- 「更换」按钮放在 `.ref-stage` 上而不是 scroll-view 内，否则会跟着图一起滚走。
- wxss 的 `.ref-stage height` 与 js 的 `STAGE_HEIGHT` 必须一致，测试有断言盯着。
