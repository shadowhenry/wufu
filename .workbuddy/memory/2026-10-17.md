## 编译报错修复：wx:else 与 wx:for 不能同节点

真机编译报 `editor.wxml:26:6 Bad attr wx:else with message: wx:if not found`。
原因：**WXML 不允许 `wx:else` 与 `wx:for` 写在同一节点上**，编译器处理 for 时会丢掉 else 的配对关系。
正确写法是用 `<block wx:else>` 包住带 `wx:for` 的子节点（`block` 不产生真实节点，不影响样式）。
editor.wxml 共 3 处（文字/图片/贴纸面板），已全部改掉。

### 给 tests/check-wxml.js 加了两条守卫（都验证过能抓到回归）
1. `wx:else` 与 `wx:for` 不得同节点。
2. `wx:else` / `wx:elif` 必须有前置的 `wx:if` 兄弟节点（编译器一次只报一个错，这里一次扫全）。

**踩坑记录（写这类静态检查时容易错的三点）**：
- 判定 `wx:else` 要看**上一个兄弟**是否带条件，不是看父节点；读栈顶会误判。
  正确做法：栈帧记录「该层级最近一个已结束子节点是否带条件」，节点结束时回写父帧。
- 自闭合标签（`<inline-notice ... />`）没有结束标签，**入栈后会永远不弹**，导致后续兄弟关系整体错位。
- `wx:else` 是**无值属性**（写成 `wx:else` 而非 `wx:else="{{x}}"`），
  用「属性名后必须有 `=`」的正则去匹配会漏掉它，必须用边界判定 `/\swx:else(\s|\/|>)/`。

`buildTextStyle` 里 `fontKey` 用的是 `compose.fontLabel()`，它返回**中文标签**（"楷体"），
而 WXML 拿它跟 `item.key`（"kai"）比较，两者永远不相等。
新增 `compose.fontKeyOf(value)` 返回预设 key，已替换。
（颜色/粗细/对齐的比较原本就是对的，只有字体错了。）

**可发现性优化**（用户没找到入口）：
1. 有文字但未选中时，面板显示指引：「点文字名称或「样式」，即可修改字体、颜色、
   字号、粗细、对齐与字距」。
2. 点**文字名称**也能选中（原来只能点小小的「样式」二字）。

测试从 12 项扩到 19 项，含「fontKey 必须是预设 key」「四种字体逐个切换选中态都对」
「一键添加的文字区同样能改样式」「面板指引存在」。已注入「fontKey 改用中文标签」
验证能抓到（3 项失败）。

## 设计界面优化（Henry 要求：多文字区/多贴纸/背景色/背景图）

**现状盘点**：五项里四项原本就具备（多处文字、多个贴纸、默认底色 #f5efe3、
切换底色），**唯一缺口是「选择背景图」**——编辑器里没有任何入口换背景图，
只能靠建板时的素材或模板决定。

**新增能力**：
1. `compose.createTextPreset(role, design)` + `TEXT_ROLE_PRESETS`：
   标题/副标题/正文/落款一键添加，位置字号按画布短边比例算
   （名片 1250×750 与易拉宝 750×1875 都验证不越界）。
2. 底色面板重构为三段：**背景颜色**（色板）→ **背景图**（缩略图 + 名称 +
   换图/移除）→ **底图不透明度**（仅在有背景图时显示，没图时调它无意义）。
3. `ensureBackgroundLayer()`：背景图被删后再次选择时重建铺满画布的底层，
   **必须插到数组首位**——绘制顺序按图层数组来，追加到末尾会盖住所有内容。
4. `applyMaterial('background', …)` 先 ensure 再替换，删了再选也能用。
5. `syncFields` 新增 `bgImage`（hasImage / displayPath / materialName）。

  同步断言会读到旧数据，要 `await flush()`。测试运行器同样必须串行（for + await）。
- 云端素材只能写 `storagePath`，本地素材写 `path`，两者不能共存
  （`applyMaterial` 已处理，测试守住）。

新增 `tests/editor-design.test.js`（12 项），已注入「背景层不再重建 + 不再置顶」
验证能抓到。

## 轮播版面调整（Henry 反馈：太小 / 不靠边 / 下方太远）

**根因不是间距不够**：几何上外缘只差 15rpx，但 ±2 档卡片旋转 52° 后
视觉宽度只剩 62%、又后退 192rpx，所以看着离边很远。
**解法是同时放大卡片 + 压低翻转与后退**，而不是单纯拉大间距：

| 参数 | 旧 | 新 |
|---|---|---|
| 卡宽 | 208rpx | 250rpx |
| TYPE_GAP | 128 | 150 |
| TYPE_TILT | 26° | 20° |
| TYPE_DEPTH | 96 | 64 |
| scale | 0.86/0.81 | 0.88/0.82 |
| 轨道高度 | 224rpx | 176rpx |
| 提示上边距 | 10rpx | 2rpx |

新几何：外侧外缘 = 2×150 + 125 = 425rpx，超出屏半宽 375rpx 约 50rpx，
视觉上正好两侧靠边（会裁掉一小截，coverflow 正常观感）。
轨道 176rpx ≈ 卡片内容 164rpx + top 6rpx，提示文字几乎贴着卡片。

新增 4 项版面守卫（卡宽≥240、轨道≤190、提示边距≤8、外缘≥375、
翻转≤24°/后退≤80），已注入旧参数验证能抓到。测试达 16 项。
